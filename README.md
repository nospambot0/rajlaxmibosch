# Rajlaxmi Enterprises — Bosch Home Appliances

Website foundation for **Rajlaxmi Enterprises**, an independently owned and operated authorised Bosch Home Appliances retailer based in Bhubaneswar, Odisha.

**Domain:** https://rajlaxmibosch.com  
**Repository:** https://github.com/nospambot0/rajlaxmibosch  
**Default branch:** main

## Stack

- Next.js App Router
- React
- TypeScript
- Custom responsive CSS

## Local development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Current scope

This first foundation commit establishes the responsive brand-led homepage, category discovery, retailer positioning, enquiry entry point and initial SEO metadata.

The product catalogue is intentionally not populated with invented models, prices, stock or product claims. The next catalogue phase should use Bosch-authorised source data and retailer-verified commercial information. Business phone, WhatsApp destination, showroom address, opening hours and approved brand assets should be added once supplied and verified.
